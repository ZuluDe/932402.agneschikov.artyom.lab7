# Лабораторная работа №7 (Вариант 9 — Статьи блога)

**Выполнил:** Агнещиков Артём вариант 9

Веб-приложение с REST API на Express и базой данных SQLite для управления статьями блога (черновики и публикации).

## Что реализовано по заданию
* Создана база данных SQLite (`blog.db`) и таблица `articles` (`id`, `title`, `content`, `is_published`, `published_at`).
* Реализованы модульные CRUD-функции в файле `db.js`.
* Настроены маршруты Express (`GET /api/articles`, `POST /api/articles`, `PUT /api/articles/:id`, `DELETE /api/articles/:id`).
* Реализована фильтрация опубликованных статей по query-параметру `?published=true` и сортировка по дате публикации (новые сверху).
* При публикации через `PUT` автоматически проставляется текущая дата `published_at`. При попытке опубликовать статью без заголовка (`title`) сервер возвращает ошибку `400`.

## Стек и библиотеки
* Node.js
* Express (`express`)
* SQLite (`sqlite3`)
* HTML, CSS, Vanilla JS

## Команды для запуска
1. Установить зависимости:
   `npm install express sqlite3`
2. Запустить сервер:
   `node server.js`
3. Открыть в браузере:
   `http://localhost:1500`
